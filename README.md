📊 E-Commerce Sales Analysis | Microsoft Excel

Data Cleaning • Exploratory Data Analysis • Business Intelligence • Interactive Dashboard




📌 Project Overview

This project focuses on analyzing an E-commerce sales dataset using Microsoft Excel. It demonstrates the process of transforming raw data into meaningful business insights through data cleaning, formula-based calculations, statistical analysis, Pivot Tables, and interactive dashboard development.

The primary objective is to understand sales performance, identify product and regional trends, and present data-driven insights that support business decision-making.

🎯 Project Objectives

Clean and validate raw sales data to improve data quality.

Apply Excel formulas for calculations, logical operations, and data transformation.

Combine multiple tables using XLOOKUP and VLOOKUP.

Analyze sales performance using Pivot Tables.

Calculate descriptive statistical measures.

Create charts and PivotCharts to visualize business trends.

Develop an interactive dashboard to present key performance indicators.

🔄 Project Workflow

1. Data Import & Organization

Imported the dataset into Excel.

Organized the data using structured Excel Tables.

Reviewed column names, data types, and data consistency.

2. Data Cleaning & Validation

Identified and removed confirmed duplicate records where appropriate.

Checked for missing values and inconsistent entries.

Corrected formatting errors in dates, numbers, currency, and text.

Standardized text values and validated important fields.

Removed irrelevant columns, if present.

3. Excel Formula Application

Applied Excel functions to calculate metrics, transform data, and support analysis.

Function

Purpose

SUM()

Calculate total values

AVERAGE()

Calculate average values

IF()

Apply logical conditions

SUMIF() / SUMIFS()

Calculate totals based on criteria

COUNTIF() / COUNTIFS()

Count records based on criteria

XLOOKUP() / VLOOKUP()

Retrieve and combine information

TRIM() / CLEAN()

Standardize text entries

4. Pivot Table Analysis

Created Pivot Tables to summarize business performance across relevant categories, such as:

Revenue by product and category.

Sales by region or store.

Units sold by category.

Customer or loyalty-tier performance, where applicable.

5. Descriptive Statistical Analysis

Calculated statistical measures using Excel formulas or the Analysis ToolPak, including:

Mean and median.

Mode.

Standard deviation.

Minimum and maximum values.

Count of observations.

These measures help understand data distribution, central tendency, and variability.

6. Data Visualization

Developed charts to present sales information clearly:

Bar/Column Charts: Compare revenue across products and categories.

Line Charts: Analyze sales trends over time, if date data is available.

Pie/Doughnut Charts: Display category contributions to total sales.

PivotCharts: Visualize summarized data dynamically.

7. Interactive Dashboard

Designed an Excel dashboard to consolidate key metrics and sales comparisons.

The dashboard includes or may include:

Total Revenue

Total Units Sold

Top-Performing Product

Best-Performing Category

Regional Sales Comparison

Interactive Slicers and Filters

The dashboard provides a consolidated view of business performance and enables users to explore relevant sales data.

📈 Business Questions

This analysis aims to answer the following questions:

What is the total revenue generated?

Which products and categories generate the highest revenue?

Which regions contribute the most and least to sales?

How do sales volumes differ across categories?

What trends and patterns can be identified in the data?

Which business areas require further investigation?

How can sales insights support inventory planning and decision-making?
